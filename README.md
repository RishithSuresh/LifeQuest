# LifeQuest

Premium gamified productivity dashboard built with Next.js, Tailwind CSS, Framer Motion, GSAP, and Three.js.

## Run locally

```bash
npm install
npm run dev
```

## Stack

- Next.js (App Router)
- React + TypeScript
- Tailwind CSS v4
- Framer Motion
- GSAP
- Three.js (@react-three/fiber + drei)
